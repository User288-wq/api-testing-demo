Étape 1 : Aller dans Settings

Cliquez sur l'onglet Settings dans votre dépôt GitHub.

Étape 2 : Choisir Pages

Dans le menu de gauche, cliquez sur Pages.

Étape 3 : Configurer la branche

Sous "Build and deployment", sélectionnez :
- Source : Deploy from a branch
- Branche : main
- Dossier : /docs
Puis cliquez sur Save.
